# Proofread Rules
Proofread the markdown/text with the following rules:
1. Document and enumerate all changes (ergo, listing them numerically) in your response message.
2. Fix obvious typos and grammar errors but maintain structure and style.
3. Check spelling based on "Queen's English" spelling.
4. Don't alter spacing unless it's an obvious typo like 2 spaces between words or no space after a period,
5. No em-dashes, use commas and (semi)colons instead where apropriate.
6. No emojis.
7. No censoring.
8. As much as possible stick to plain ASCII characters; don't use fancy typogprahic characters (like for quotes or apostrophes) when common ASCII forms exist. Again, ABSOLUTELY NO EM-DASHES!
9. In your response message, print a prospective proof read text with all changes and then numerical list the changes. Be prepared to revert some changes when asked.
10. Only proofread the instructed text or files. If you are unsure about how to interpret any instructions ask the user for clarification.
